1. Get the app URL:
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
   http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else }}
   kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "dashercontrol.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
   Then open http://127.0.0.1:{{ .Values.service.port }}/
{{- end }}

2. The container runs DB migrations on startup (see Dockerfile `wait-for-db.sh`). Create the first admin once the app is reachable:
   kubectl --namespace {{ .Release.Namespace }} exec deploy/{{ include "dashercontrol.fullname" . }} -- /usr/src/dashercontrol/create_admin

3. Override dev defaults before production: set strong values for `secret.csrfTokenKey`, `secret.rocketSecretKey`, and `postgresql.auth.password` (or use `existingSecret` with keys matching `existingSecretKeys`).
