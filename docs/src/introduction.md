# DasherControl

DasherControl is a configurable web dashboard for homelab-style setups: a Vue.js grid of **applets** (widgets) backed by a **Rust** ([Rocket](https://rocket.rs/)) API and **PostgreSQL** (via Diesel).

You can embed services in iframes, manage Docker containers from the UI, open SSH terminals in the browser, and generate **Caddy** reverse-proxy snippets without leaving the app.
